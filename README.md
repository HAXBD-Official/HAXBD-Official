## ⚡ Who We Are

**HAXBD** is a hardware security research and development group based in Bangladesh 🇧🇩.

We focus on designing and building **custom hardware tools** for the cybersecurity space — physical devices aimed at ethical hackers, penetration testers, security researchers, and CTF players.

We are currently in active development. Details about our work will be shared when the time is right.

---

## 🔧 What We Do

```
[ Hardware Design        ]  →  Custom PCB & embedded device development
[ Firmware Engineering   ]  →  Low-level firmware for security hardware
[ Security Research      ]  →  USB, HID, WiFi, and wireless attack surfaces
[ Tool Development       ]  →  Practical tools for authorized security testing
[ CTF & Red Team Tools   ]  →  Devices built for real-world security scenarios
```
