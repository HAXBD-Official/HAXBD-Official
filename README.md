## ⚡ About HAXBD

> We build **open-source security hardware** — physical tools for USB HID injection, wireless recon, keylogging, and loot capture. Everything we make is designed for **authorized penetration testing, CTF competitions, and security education**.

- 🔴 Building the **HAX•STIK** — a custom USB HID injection device with a full web-based OS
- 🛠️ All tools are open-source and community-driven
- 🌐 Based in **Bangladesh** 🇧🇩
- 🎯 Focus: Hardware hacking · USB HID · WiFi recon · Embedded security
- ⚖️ Everything we build is for **ethical, authorized use only**

## 🤝 Contribute

We welcome contributions to any of our repositories:

- 🔴 **Firmware bugs / features** → [HAXSTIK_OS Issues](https://github.com/HAXBD-Official/HAXSTIK_OS/issues)
- 📦 **New payloads** → [Haxstik_Payload](https://github.com/HAXBD-Official/Haxstik_Payload) — fork, write, PR
- 💬 **Ideas & feedback** → Open a GitHub Discussion or Issue

**Contribution rules:**
- Only ethical, authorized-use payloads accepted
- All code must be tested on real hardware or emulator
- Follow the payload template format in Haxstik_Payload
